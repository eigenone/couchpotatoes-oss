# Changelog

All notable changes to this project are documented here. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and the project uses [Semantic Versioning](https://semver.org/).

## [Unreleased]

### Added
- Security policy, changelog, pull request template and Dependabot config.

## [0.0.1] - 2026-11-15

### Added
- `@couchpotatoes/engine` skeleton: seeded randomness (`createRandom`), game definitions (`defineGame`, `createGame`), turn order, move validation with `invalid()`, move log and deterministic `replay()` ([#12](https://github.com/eigenone/couchpotatoes-oss/pull/12)).
- npm workspaces monorepo with TypeScript, Vitest and CI on Node 22 and 24.
- Project website at https://couchpotatoes.eigen1.com.
- Contributing guide, Code of Conduct and issue templates.
