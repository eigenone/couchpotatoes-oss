What's inside

Everything under the table, so you can focus on the game.

Most digital tabletop games rebuild the same groundwork: state, rules, turns, shuffling, syncing players and a UI that feels good in the hand. CouchPotatoes packages that groundwork into pieces you can pick and choose.

Game engine

The rules brain of your game: deterministic, testable and easy to reason about.

  • Game state, turns & phases
  • Rules validation & legal moves
  • Seeded randomness for dice & shuffles

UX components

Reusable, accessible building blocks that make a game feel great to play.

  • Boards, cards, hands & decks
  • Tokens, timers & score tracking
  • Lobbies, invites & game flow

Frameworks

Opinionated patterns and tooling that take you from prototype to playable.

  • Project structure & templates
  • Rule testing & simulation
  • Local and online multiplayer

Idea to prototype

Describe your rules. Play tonight.

Define how your game works, and CouchPotatoes handles turn order, legal moves, shuffling and keeping every player in sync. Swap in our components or bring your own UI.

Illustrative API. The engine is being designed in the open, so shapes may change. Come help decide.

import { defineGame, deck } from '@couchpotatoes/engine'

export default defineGame({
  name: 'High Card',
  players: { min: 2, max: 6 },

  setup: ({ players, random }) => ({
    deck: random.shuffle(deck.standard52()),
    hands: players.map(() => []),
  }),

  moves: {
    draw: ({ state, player }) => {
      state.hands[player].push(state.deck.pop())
    },
  },

  // Turn order, validation and sync are handled for you
  turn: { order: 'clockwise', movesPerTurn: 1 },
})

How we build

Developed in the open, with the community.

CouchPotatoes is a community project. Planning, design and code all happen on GitHub where anyone can follow along and pitch in.

01

Public roadmap & discussions

Design proposals, feature requests and decisions happen in GitHub Issues and Discussions, not behind closed doors.

02

Community-driven

Anyone can propose ideas, report bugs, or contribute code, art, docs and example games.

03

Small, reviewable changes

Work lands through pull requests reviewed by maintainers and the community.

04

Modular by design

The engine, UX and frameworks stay loosely coupled. Adopt only the pieces you need.

05

Free and MIT licensed

Use it for hobby projects, game jams, classrooms or commercial games. No strings attached.

06

Original games only

Our examples showcase original designs and public-domain classics, and we respect the IP of existing games.
