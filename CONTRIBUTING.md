# Contributing to CouchPotatoes

Thanks for your interest in CouchPotatoes! We're building an open source game engine, UX toolkit and framework for digital board and card games, and we welcome contributions of every kind.

## Ways to contribute

- **Ideas and design feedback**: start a [discussion](https://github.com/eigenone/couchpotatoes-oss/discussions) about features, APIs or game types we should support.
- **Bug reports**: open an [issue](https://github.com/eigenone/couchpotatoes-oss/issues) with steps to reproduce, what you expected, and what happened.
- **Code**: pick up an open issue, or propose a change in a discussion first if it's large.
- **Docs, examples, art and playtesting**: all equally valuable. Tell us what you'd like to help with.

## Making a change

1. Fork the repository and create a branch from `main` (for example `feat/deck-shuffle` or `fix/turn-order`).
2. Keep pull requests small and focused on one thing. Smaller changes are reviewed faster.
3. Write a clear description of **what** you changed and **why**. Link any related issue.
4. Be responsive to review feedback. Maintainers and community members review every pull request.

## Project website

The site at https://couchpotatoes.eigen1.com is the static `index.html` in this repo (no build step). To preview locally:

```sh
python3 -m http.server 8000
# then open http://localhost:8000
```

## Intellectual property

CouchPotatoes examples and templates feature only **original game designs** and **public-domain classics** (chess, checkers, standard-deck card games, and so on). Please don't contribute names, artwork, rules text, or other assets from existing commercial games.
